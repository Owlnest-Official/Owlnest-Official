## Sharing and presentation

| Rule | Requirement |
| --- | --- |
| EN / ZH | One page family: identical image paths, slot order, and presentation. Alt text is short and natural in each language. |
| Cross-family reuse | Prohibited, including social-preview and structured-data image references. Do not fill a removed slot with another family's photo. |
| Zero-photo pages | Science, Evidence, Sleep Lab, FAQ, Reviews, Contact, Policy, and Account contain no content photos. Logos and functional UI icons are exempt. |
| Science | Preserve the two existing HTML / CSS / SVG educational diagrams. Keep conceptual labels; never imply measured Lume SPD, laboratory tests, or participant data. |
| Home animation | Protect `/001.png`–`/096.png`: all 96 frames, exact numbering and filenames, existing animation logic. Not a content-photo slot. No re-export or JPG replacement. |
| Framing | Preserve original proportions and the product, base, and relevant controls. Use orientation-correct dimensions and uncropped responsive images; no original-image edits. |
| Rhythm | Keep existing editorial typography and generous section/image spacing. Do not add filler copy, cards, icons, or photos to occupy whitespace. |
| Sharing previews | Use that family's approved image or the shared logo. Zero-photo families use the logo, not a borrowed product photo. |
