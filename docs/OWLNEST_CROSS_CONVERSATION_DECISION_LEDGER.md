## 2. Status vocabulary

- **CURRENT**: approved and authoritative now.
- **RETIRED**: previously used, but must not be restored as current positioning or behavior.
- **CONDITIONAL**: allowed only in a defined context with qualifiers.
- **PENDING EVIDENCE**: cannot be asserted until product-specific records exist.
- **NEEDS REPO AUDIT**: current decision is known, but the repository may still contain conflicting residues.
- **UNVERIFIED**: source conflict or missing confirmation; do not publish as fact.
- **PROTECTED SYSTEM**: do not alter without an explicit user request.
